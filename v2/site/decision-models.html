Method

How it was tested

  • Only items created after Sep 15, 2026, after every model's release, so none can be in training data.
  • Inputs are what a triager sees at filing time. Labels, template markers, CVSS scores, CWE numbers and the PR author's role were removed.
  • Option descriptions come from the sources: Bugzilla's component texts, Mozilla's severity scale, GitHub's advisory scale, MITRE's CWE definitions.
  • Classes balanced; balanced accuracy is the primary metric; Brier score and calibration error are reported for probability quality.
  • Drex Max v1.1 was tested on Nace's own API; the other six through OpenRouter. The earlier v1.0 run (OpenRouter) is archived in the repository.
  • Every comparison uses a paired bootstrap (2,000 resamples) with Holm correction across all 21 model pairs.
Limits

What this doesn't show

  • English, software-engineering text only; no images.
  • Labels are human decisions and contain mistakes: on 385 items all seven models agree with each other but not with the label. They're listed for audit.
  • Many CVE descriptions name their weakness ("cross-site scripting"), which makes parts of the CWE task easy.
  • Only Jev and Luna had 10 or more relevant Hacker News mentions; the others got a neutral reviews score.
  • Prices, uptime and usage are a snapshot from Nov 6, 2026. Latency also reflects each model's host.
  • Two items were dropped for every model: one advisory that Nace's API rejects (it embeds an image as a data URL) and one that d1-ultra never answered.
